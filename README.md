# 🎓 Career Aspiration Prediction using Machine Learning

This project predicts a student's future career aspiration based on academic performance, study habits, and personal factors using supervised machine learning models.

The system analyzes features such as subject scores, self-study hours, extracurricular activities, attendance, and demographic information to classify students into career categories like Doctor, Engineer, Lawyer, Artist, etc.

---

## 🚀 Features
- Data preprocessing and cleaning
- Label encoding and feature scaling
- Handling class imbalance with resampling
- Multiple ML model comparison
- Random Forest classifier with high accuracy
- Career prediction for new student input
- Saved encoder, scaler, and trained model

---

## 🧠 Machine Learning Models Used
- Logistic Regression
- Support Vector Machine
- Random Forest (Best Model)
- K-Nearest Neighbors
- Decision Tree
- Gradient Boosting
- AdaBoost

---

## 📊 Model Performance
Best performing model: **Random Forest Classifier**  
Accuracy: **93%**
